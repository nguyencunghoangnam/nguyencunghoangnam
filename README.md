## Hệ tọa độ nghề nghiệp

| Trục | Mô tả |
|---|---|
| **Toán học** | Thiết kế bài giảng, đề kiểm tra, công cụ minh họa và hoạt động học tập theo CTGDPT 2018. |
| **EdTech** | Xây dựng web app nhỏ, dashboard, công cụ tương tác và workflow hỗ trợ giáo viên. |
| **AI trong giáo dục** | Ứng dụng AI để tạo học liệu, tự động hóa tác vụ lặp lại và cá nhân hóa trải nghiệm học tập. |
| **Thiết kế trải nghiệm** | Ưu tiên giao diện đẹp, rõ ràng, dễ dùng ngay trong lớp học. |

> Phương châm làm việc: **dùng Toán để tạo cấu trúc, dùng công nghệ để tăng lực dạy học.**

## Định hướng sản phẩm

```text
Lớp học thực tế
   -> vấn đề dạy học cần giải quyết
      -> công cụ nhỏ, rõ mục tiêu
         -> thử nghiệm với học sinh
            -> cải tiến thành học liệu có thể tái sử dụng
```
